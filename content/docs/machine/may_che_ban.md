# Máy/Trạm Chế Bản

Trạm chế bản: soát lỗi/kiểm tra file chữ và ảnh, dàn trang, bình bản, RIP và ghi hiện bản.
Năng lực và nhân lực của trạm là thuộc tính của trạm, không nhập lại theo từng đơn.


# Thông Số

- **Năng lực soát lỗi, kiểm tra file chữ**
  * *Năng lực kiểm tra file chữ trung bình của một nhân viên.*
  * *Đơn vị*: Trang/Phút

- **Nhân lực soát lỗi, kiểm tra file chữ**
  * *Số nhân lực tham gia kiểm tra file chữ.*
  * *Đơn vị*: Người|Thiết bị

- **Năng lực xử lý ảnh, kiểm tra file ảnh**
  * *Năng lực xử lý/kiểm tra file ảnh trung bình của một nhân viên.*
  * *Đơn vị*: Trang/Phút

- **Nhân lực xử lý ảnh, kiểm tra file ảnh**
  * *Số nhân lực tham gia xử lý/kiểm tra file ảnh.*
  * *Đơn vị*: Người|Thiết bị

- **Năng lực xử lý dàn trang**
  * *Thời gian planning trung bình để dàn một trang; giá trị càng nhỏ thì trạm xử lý càng nhanh.*
  * *Đơn vị*: Phút/Trang
